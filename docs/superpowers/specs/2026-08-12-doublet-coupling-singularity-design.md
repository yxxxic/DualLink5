# DualLink5 机构双元耦合奇异性分析设计

日期：2026-08-12

状态：已批准

范围：单侧驱动条件下的完整刚性闭环运动学与耦合奇异性，不包含动力学和控制

## 1. 背景与目标

DualLink5 由上下两个中心对称的五连杆机构组成，共享中间连杆，并通过两个真实存在的平行四边形传动机构传递角度。当前实物采用下方单侧主动驱动，上方五连杆通过机械闭环被动跟随。

实验观察表明：当下方驱动角 `phi` 接近 `0 deg` 时，下方 `theta`、`phi` 电机仍保持位置闭环，但上方 `A_(k+1)G_k` 与 `C_(k+1)G_k` 同时失去可靠约束，`G_k = B_(k+1)` 在重力作用下明显下垂。该现象在 `phi` 的正负两侧都会发生，暂以 `abs(phi) <= 10 deg` 作为工程危险区。

现有程序只对单个五连杆进行经典 Type-I、Type-II 和 Type-III 奇异分析，并通过理想中心对称变换生成上方机构。两个平行四边形目前只根据已求出的五连杆姿态构造绘图点，没有作为真实闭环参与求解，因而无法识别上述被动侧失控现象。

本功能的目标是建立完整的单侧驱动刚性闭环运动学，解释、检测并绘制这一机构双元耦合奇异性，同时保持现有单五连杆分析及其他公共接口兼容。

## 2. 已确认的物理拓扑

### 2.1 主要铰点

- `G_k` 与 `B_(k+1)` 是同一物理点。
- `A_(k+1)` 不是全局机架固定点，但在所观察的失控运动中受其他传动链强约束，位移很小。
- 下方 `theta_l`、`phi_l` 均保持位置闭环；失控发生在上方被动五连杆。

### 2.2 alpha 平行四边形

- `Palpha1`、`E_k`、`Palpha4` 固定在同一根刚性主连杆 `A_k E_k` 上。
- `Palpha2`、`D_k`、`Palpha3` 固定在同一根刚性主连杆 `D_k A_(k+1)` 上。
- `Palpha1-Palpha2` 与 `Palpha4-Palpha3` 是两根独立的平行传动连杆。
- 四个 `Palpha` 点均为实际转动铰链。

### 2.3 beta 平行四边形

- `Pbeta1`、`E_k = D_(k+1)`、`Pbeta4` 固定在同一根上方刚性主连杆 `C_(k+1)D_(k+1)` 上。
- `Pbeta2`、`D_k = E_(k+1)`、`Pbeta3` 固定在同一根下方刚性主连杆 `C_kD_k` 上。
- `Pbeta1-Pbeta2` 与 `Pbeta4-Pbeta3` 是两根独立的平行传动连杆。
- 四个 `Pbeta` 点均为实际转动铰链。

### 2.4 已有尺寸

主五连杆长度继续使用 `defaultGeometry`：

- `link1 = A_kE_k = 80 mm`
- `link2 = B_kC_k = 62 mm`
- `link3 = C_kD_k = 69 mm`
- `link4 = D_kE_k = 80 mm`
- `link5 = A_kB_k = 80 mm`

平行四边形实际铰接距离继续使用已有参数：

- `E_k-Palpha1 = 30 mm`
- `Palpha1-Palpha4 = 60 mm`
- `D_k-Pbeta2 = 30 mm`
- `Pbeta2-Pbeta3 = 60 mm`

这些距离用于构造真实铰点、检验刚体共线关系、平行四边形闭环长度及绘图，不再只是视觉辅助参数。

## 3. 数学模型

### 3.1 平行四边形的理想方向传递

两个平行四边形分别传递主连杆方向。在理想刚性模型中：

```text
p_Aupper = p_Dlower + (p_Elower - p_Alower)
p_Cupper = p_Elower + (p_Dlower - p_Clower)
```

因此：

```text
p_Aupper - p_Cupper = p_Clower - p_Alower
```

并有：

```text
|A_(k+1) C_(k+1)| = |A_k C_k|
```

下方三角形满足：

```text
|A_k C_k|^2 = AB^2 + BC^2 - 2 AB BC cos(phi)
```

当 `phi = 0 deg` 时：

```text
|A_k C_k| = |80 - 62| = 18 mm
```

上方点 `G_k` 同时受到：

```text
|A_(k+1) G_k| = 80 mm
|C_(k+1) G_k| = 62 mm
```

的约束。两个约束圆在圆心距为 `18 mm` 时发生内切，故 `A_(k+1)`、`C_(k+1)`、`G_k` 共线，上方被动闭链到达几何奇异构型。

### 3.2 耦合约束矩阵

令：

```text
u_AG = (p_G - p_Aupper) / |p_G - p_Aupper|
u_CG = (p_G - p_Cupper) / |p_G - p_Cupper|
```

对上方两根定长约束微分，得到 `G_k` 的速度约束矩阵：

```text
A_G = [u_AG^T; u_CG^T]
```

完整速度关系写为：

```text
A_G * pG_dot = B_G * qLower_dot
```

其中 `B_G` 描述下方主动关节运动经两个平行四边形引起的上方两个圆心运动。常规构型下 `A_G` 满秩，可唯一求得 `pG_dot`；接近内切时，`A_G` 的两行趋于平行，速度传递不再唯一。

锁定下方电机时 `qLower_dot = 0`，若 `A_G` 退化，则存在：

```text
A_G * n ~= 0
```

的近似零空间方向 `n`。该方向垂直于接近共线的两根上方连杆，对应实物中 `G_k` 最容易移动的方向。纯运动学给出正反两个等价方向；实际向下运动由重力选择，本功能不模拟重力。

### 3.3 指标和分类

主要无量纲耦合裕度定义为：

```text
s_c = abs(cross2(u_AG, u_CG))
```

其中 `s_c` 位于 `[0,1]`：

- `s_c = 1`：两根约束连杆接近垂直，约束能力较好；
- `s_c -> 0`：两根连杆接近共线；
- `s_c = 0`：理论耦合奇异。

同时计算：

- `sigmaMin`：`A_G` 的最小奇异值；
- `conditionNumber`：`A_G` 的条件数；
- `passiveDirection`：`A_G` 最小奇异值对应的右奇异向量；
- `exactCouplingSingular`：理论耦合奇异标志；
- `engineeringWarning`：经验危险区标志；
- 完整有效性和状态码。

该奇异性在整体层面命名为 **mechanism-doublet coupling singularity**，在经典闭链分类中注明为 **internal-tangency Type-II singularity of the passive upper five-bar loop**。

## 4. 软件架构

### 4.1 新增运动学求解器

新增：

```text
+duallink5/+kinematics/forwardPassiveDoublet.m
```

输入下方主动角 `qLower = [thetaLower, phiLower]`，输出：

- 下方五连杆构型；
- 两个平行四边形的全部实际铰点；
- `A_(k+1)`、`C_(k+1)`；
- `G_k` 的两个圆交点候选；
- 按参考构型或上一构型连续性选定的装配分支；
- 上方完整五连杆；
- 主连杆、两个平行四边形及理想对称关系的几何残差；
- 稳定、可区分的状态码。

求解器不得通过中心对称变换直接生成上方机构。理想对称结果只用于验证真实闭环求解结果。

现有 `forwardAssembly` 第一版保持不变，以降低回归风险。

### 4.2 单构型耦合评估器

新增：

```text
+duallink5/+singularity/evaluateCoupling.m
```

它复用完整被动 doublet 构型，构造 `A_G`、`B_G`，并使用 SVD 计算耦合指标和自运动方向。接近奇异时不得直接求矩阵逆。

### 4.3 耦合奇异空间采样器

新增：

```text
+duallink5/+singularity/sampleCouplingSpace.m
```

在 `(thetaLower, phiLower)` 网格上分层保存：

- 理论几何可达性；
- 机械连续有效性；
- 碰撞、闭链不可达、装配拓扑改变等原因；
- `s_c`、`sigmaMin`、条件数、自运动方向；
- 理论奇异与工程危险区；
- `G_k` 任务空间坐标。

参考装配模式默认为 `(85 deg, 30 deg)`。相对于该参考模式，不能连续穿过 `phi = 0 deg` 后静默切换圆交点分支。负 `phi` 理论区域仍需绘制；研究负侧机械连续区时可使用 `(85 deg, -30 deg)` 作为参考重新采样。

### 4.4 可视化

新增：

```text
+duallink5/+viz/plotCouplingSingularitySpace.m
```

图面包含：

1. 关节空间：`thetaLower-phiLower`，颜色表示耦合裕度或条件数；
2. 任务空间：`G_k(x,y)`，颜色保持与关节样本一致；
3. 代表性完整机构：正常、近奇异和理论奇异构型，并在 `G_k` 处绘制 SVD 得到的双向自运动箭头。

必须明确区分：

- `phi = 0 deg` 理论奇异线；
- `-10 deg <= phi <= 10 deg` 工程危险带；
- 几何不可达或机械非法区域；
- 当前参考装配模式下不连续的另一分支。

### 4.5 配置、门面和脚本

`defaultGeometry` 新增可配置参数：

```matlab
geometry.analysis.couplingWarningAngle = deg2rad(10);
```

`DL5` 门面类增加只读方法：

```matlab
result = model.couplingSingularity(qLower, options);
samples = model.sampleCouplingSingularitySpace(grid, options);
```

新增日常入口：

```text
scripts/analyze_coupling_singularity.m
```

脚本生成批准的耦合奇异空间图，并输出各分类样本数量和参考构型指标摘要。

## 5. 分支、有效性与错误处理

- 默认参考构型为 `(85 deg, 30 deg)`，并保持其圆交点和闭环装配拓扑。
- 支持上一构型连续性选择，防止两个 `G_k` 候选点之间跳变。
- 理论奇异点允许返回有效的奇异几何和有限的自运动方向，不得因矩阵不可逆崩溃。
- 穿越理论奇异线时报告分支合并或拓扑边界，不得静默切换装配模式。
- 几何不可达、碰撞、拓扑改变、耦合奇异和工程警告使用独立状态或掩码。
- 单个非法样本不得终止整个空间扫描。
- 不可计算数值使用 `NaN`，不能用零伪装。
- 公共输入校验产生稳定的 `duallink5:*` 错误标识，不泄露随机 MATLAB 原生错误。

## 6. 验证与验收标准

### 6.1 参考构型

对 `(85 deg, 30 deg)`：

- 完整被动 doublet 求解有效；
- 主要铰点与现有理想对称模型在容差内一致；
- 两个平行四边形所有长度及刚体共线残差在容差内；
- `A_G` 满秩，耦合指标远离零；
- 不属于工程危险区。

### 6.2 理论奇异构型

对 `phi = 0 deg`：

- `|A_(k+1)C_(k+1)| = 18 mm`；
- `A_(k+1)`、`C_(k+1)`、`G_k` 共线；
- 两个上方约束圆内切；
- `exactCouplingSingular = true`；
- `A_G` 秩下降，`sigmaMin` 接近零；
- 自运动方向与共线连杆方向垂直；
- 求解和绘图均不得崩溃。

### 6.3 正负对称与工程边界

- 对相同 `theta` 的 `phi = +5 deg` 与 `phi = -5 deg`，耦合裕度量级相同，二者都进入工程危险区；
- `abs(phi) = 10 deg` 按包含边界处理；
- `abs(phi) > 10 deg` 时仅退出角度经验警告，其他理论近奇异指标仍独立生效；
- 图中必须显示理论正负两侧，不得因默认正侧参考构型删除负侧理论区域。

### 6.4 连续性、绘图与回归

- 连续轨迹不发生未报告的圆交点分支跳变；
- 关节空间中存在 `phi = 0 deg` 理论线和 `+/-10 deg` 工程边界；
- 任务空间颜色与对应关节样本一致；
- 自运动箭头来自 SVD，不得人工固定为向下；
- 绘图不污染传入 axes 状态，不遗留隐藏 figure；
- 所有现有单五连杆奇异、工作空间、运动 UI 和固定构型测试继续通过；
- `scripts/plot_fixed_pose.m` 保持可运行；
- 所有新增生产 MATLAB 文件通过 `checkcode(..., '-id')`。

## 7. 本次不包含

- 连杆质量、质心和重力；
- 下垂量或时间响应的动力学预测；
- 扭簧刚度、柔性变形、摩擦、间隙和阻尼；
- 四电机冗余驱动力矩分配；
- 内力控制、阻抗控制或导纳控制；
- 用实验数据标定真实危险角度。

后续可在纯运动学模型通过实物构型验证后，继续增加弹性、冗余驱动和控制分析。

## 8. 最终交付定义

完成后，程序应能够用完整刚性闭环运动学说明并显示：

> 单侧驱动时，下方 `phi` 接近零会使上方被动五连杆的两个约束圆接近内切，导致 mechanism doublet 的耦合约束矩阵退化，并产生与实物上方机构下垂相符的 `G_k` 近似自运动方向。
